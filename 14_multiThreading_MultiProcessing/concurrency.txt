================================================================================
                    CONCURRENCY vs PARALLELISM (Complete Cheatsheet)
================================================================================

1. SABSE AASAN DEFINITION (1-Line Summary)
--------------------------------------------------------------------------------
* Concurrency : "DEALING WITH multiple things at once" (Ek saath manage karna)
* Parallelism : "DOING multiple things at once"        (Ek saath sach-much chalana)


2. REAL-LIFE EXAMPLE (Kabhi nahi bhoolne wala example!)
--------------------------------------------------------------------------------
Scenario: Kitchen mein Breakfast banana hai (Chai + Toast + Omelette)

A) CONCURRENCY (Single Chef = 1 CPU Core):
   - Kitchen mein akela ek Chef hai.
   - Usne chai ka paani gas pe chadhaya (ab paani ubal raha hai - waiting time).
   - Paani ubalne ke dauran Chef khada nahi raha, usne bread toaster mein daal di.
   - Jab tak toast ho raha hai, usne ande fod kar omelette bana liya.
   --> Chef AKELA hai, ek waqt pe hath se ek hi kaam kar raha hai,
       lekin tasks ke beech itni smartly switch kar raha hai ki sab kaam
       ek saath aage badh rahe hain. (Illusion of simultaneous work)

B) PARALLELISM (Multiple Chefs = Multiple CPU Cores):
   - Kitchen mein 3 alag-alag Chefs hain.
   - Chef 1: Chai bana raha hai.
   - Chef 2: Toast sek raha hai.
   - Chef 3: Omelette fry kar raha hai.
   --> Teeno chefs bilkul EK HI PAL (exact same time) par alag-alag kaam
       sach mein parallelly kar rahe hain. (True simultaneous execution)


3. VISUAL DIAGRAM (Computer CPU Level pe kaise hota hai)
--------------------------------------------------------------------------------
[ CONCURRENCY - 1 CPU Core ] (Time Slicing / Context Switching)
Time  --->
Core 1: [ Task 1 ] -> [ Task 2 ] -> [ Task 1 ] -> [ Task 3 ] -> [ Task 2 ]
(CPU rapidly switch karta hai, insaan ko lagta hai sab ek saath chal raha hai)

[ PARALLELISM - Multi-Core CPU ] (True Simultaneous Execution)
Time  --->
Core 1: [============ Task 1 ============]
Core 2: [============ Task 2 ============]
Core 3: [============ Task 3 ============]
(Har core apna alag task independent bina ruke chalata hai)


4. PYTHON KI DUNIYA MEIN (Threading vs Multiprocessing)
--------------------------------------------------------------------------------
Python mein ek cheez hoti hai: GIL (Global Interpreter Lock).
GIL ki wajah se Python ke threads ek time par ek hi CPU Core use kar sakte hain!

Isliye:
--------------------------------------------------------------------------------
Feature                 | Concurrency (Threading/Async)  | Parallelism (Multiprocessing)
--------------------------------------------------------------------------------
Python Module           | `threading` / `asyncio`        | `multiprocessing`
Hardware Requirement    | 1 Core bhi chalega             | Minimum 2 ya zyada Cores
Kaise Kaam Karta Hai?   | Context Switching / Waiting    | Multiple Processes on diff Cores
Best For                | I/O Bound Tasks                | CPU Bound Tasks
Memory                  | Memory share hoti hai (Shared) | Har process ki alag memory hoti hai
GIL ka Asar             | GIL se bound rehta hai         | GIL bypass ho jata hai (alag Python instance)
--------------------------------------------------------------------------------

* I/O Bound Tasks kya hain? (Wait karne wale kaam)
  - Internet se file download karna, API se data fetch karna,
  - Database se query chalana, Hard disk par file read/write karna.
  --> Solution: Use THREADING or ASYNCIO (Concurrency is enough!)

* CPU Bound Tasks kya hain? (Heavy Calculation wale kaam)
  - 1 se 10 crore tak numbers ka sum nikalna,
  - Image/Video processing, Machine Learning model train karna, Encryption.
  --> Solution: Use MULTIPROCESSING (Parallelism chahiye!)


5. QUICK CODE SKELETON (Dekhte hi yaad aane ke liye)
--------------------------------------------------------------------------------

A) Concurrency (Threading - for I/O):
   import threading
   import time

   def download_file(file_name):
       print(f"Downloading {file_name}...")
       time.sleep(2) # Simulating network wait
       print(f"{file_name} downloaded!")

   t1 = threading.Thread(target=download_file, args=("file1.zip",))
   t2 = threading.Thread(target=download_file, args=("file2.zip",))
   t1.start()
   t2.start()
   t1.join()
   t2.join()

B) Parallelism (Multiprocessing - for heavy CPU work):
   import multiprocessing

   def heavy_calculation(n):
       return sum(i * i for i in range(n))

   if __name__ == "__main__":
       p1 = multiprocessing.Process(target=heavy_calculation, args=(10_000_000,))
       p2 = multiprocessing.Process(target=heavy_calculation, args=(10_000_000,))
       p1.start()
       p2.start()
       p1.join()
       p2.join()

- RUNNING A RACE       = PARALLELISM  (3 Runners, 3 alag tracks pe ek saath bhaag rahe hain)
