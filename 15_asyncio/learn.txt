1. WHAT IS ASYNCHRONOUS PROGRAMMING (asyncio)?
--------------------------------------------------------------------------------
- Definition: Ek programming paradigm jisme ek single thread multiple I/O tasks 
  (network requests, database queries, file reading) ko bina ek dusre ko block kiye 
  concurrently handle kar sakta hai.
- Real-life Analogy (The Smart Chef):
  * Synchronous: Chef ne toast banne rakha aur 2 minute samne khada raha (Time waste).
  * Multithreading: 10 chefs hire kiye (Heavy memory & context switching cost).
  * Asyncio: 1 akela Chef - Toast machine me daala (await), jab tak toast ban raha 
    hai, tab tak coffee bana li! Jaise hi toast bana, wapas toast nikaal liya.
- Scalability: Thousands of concurrent network connections ko handle karne ke liye 
  hume hazaron threads/processes nahi banane padte; asyncio single thread me hi 
  cooperative multitasking se ye kaam kar leta hai.


2. THE CORE BUILDING BLOCKS
--------------------------------------------------------------------------------
[A] EVENT LOOP (The Traffic Controller / Manager)
    - Kya hai: Asyncio ka dil (Heart). Ye ek continuous loop hai jo monitor karta 
      hai ki kaunsa task wait kar raha hai aur kaunsa task chalne ke liye ready hai.
    - Kaam: Jab koi task 'await' karta hai, event loop control lekar dusre task ko 
      chala deta hai.

[B] async def (Declaring a Coroutine)
    - Normal function seedha execute hota hai.
    - 'async def' se bana function seedha execute NAHI hota; call karne par ye 
      ek "Coroutine Object" return karta hai jisko pause aur resume kiya ja sakta hai.
    - Example:
        async def fetch_data():
            return "Data received"

[C] await (The Pause & Yield Button)
    - Sirf 'async def' functions ke andar hi use ho sakta hai.
    - Kaam: Yeh coroutine ko pause kar deta hai jab tak result na aa jaye, aur 
      control Event Loop ko de deta hai taaki Event Loop doosre tasks run kar sake.
    - Example:
        data = await fetch_data()

[D] asyncio.run(main()) (The Entry Point)
    - Python 3.7+ mein program start karne ka standard tareeqa.
    - Kaam:
        1. Naya Event Loop create karta hai.
        2. Main coroutine ko run karta hai jab tak wo finish na ho jaye.
        3. Finish hone ke baad loop ko gracefully close kar deta hai.
    - Example:
        asyncio.run(main())


3. IMPORTANT BUILT-IN FUNCTIONS
--------------------------------------------------------------------------------
[1] asyncio.sleep(seconds) -> Non-blocking Delay
    - time.sleep(2) poore thread ko freeze kar deta hai (koi doosra kaam nahi ho sakta).
    - await asyncio.sleep(2) sirf is specific coroutine ko 2 sec ke liye pause karta 
      hai, jabki event loop doosre tasks ko execute karta rehta hai.

[2] asyncio.create_task(coroutine) -> Background Task Scheduling
    - Kaam: Coroutine ko Event Loop ke schedule queue mein turant daal deta hai.
    - Fayda: Ye turant ek Task object return karta hai aur background mein run hona 
      shuru ho jata hai bina execution ko roke.
    - Example:
        task1 = asyncio.create_task(download_file("file1.png"))
        task2 = asyncio.create_task(download_file("file2.png"))
        await task1
        await task2

[3] asyncio.gather(*coroutines) -> Run Multiple Tasks Concurrently
    - Kaam: Multiple coroutines ko ek sath run karta hai aur sabhi ke results ko 
      ek ordered list ke roop mein lautaata hai.
    - Example:
        results = await asyncio.gather(task1(), task2(), task3())
        # results = [res1, res2, res3]

[4] asyncio.wait_for(coroutine, timeout) -> Timeout Protection
    - Kaam: Agar koi coroutine diye gaye seconds ke andar khatam nahi hoti, toh ye 
      asyncio.TimeoutError raise kar deta hai.
    - Example:
        try:
            res = await asyncio.wait_for(fetch_api(), timeout=5.0)
        except asyncio.TimeoutError:
            print("API response timed out!")

[5] asyncio.wait(coroutines) -> Low-level Fine-grained Control
    - Kaam: Multiple tasks ka wait karta hai par options deta hai jaise:
      * FIRST_COMPLETED: Jaise hi pehla task complete ho, aage badho.
      * ALL_COMPLETED: Jab sabhi complete hon tab aage badho.
    - Returns: (done_set, pending_set)


4. QUICK COMPARISON (When to use what?)
--------------------------------------------------------------------------------
| Feature          | Multiprocessing     | Multithreading       | Asyncio             |
|------------------|---------------------|----------------------|---------------------|
| Ideal For        | CPU-heavy tasks     | I/O tasks (blocking) | I/O tasks (network) |
| Architecture     | Multiple Processes  | Multiple Threads     | Single Thread       |
| Memory Usage     | High                | Medium               | Very Low            |
| Parallelism      | True Parallel (Cores)| GIL Limited         | Cooperative (Loop)  |
