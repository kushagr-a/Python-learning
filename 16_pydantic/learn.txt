1. Pydantic Kya Hai?
--------------------
Pydantic Python ki ek popular library hai jo runtime par:
- Data ko VALIDATE karti hai (kya data sahi format me hai?)
- Data ko PARSE karti hai (compatible data ko sahi type me convert karna)

Simple words me: Ye aapke program ka "Security Guard" hai jo bahar se 
aane wale data (API, JSON, User Input) ko andar aane se pehle check karta hai.


2. Iski Zaroorat Kyu Hai?
-------------------------
- Galat data ko program ke andar aage badhne se rokta hai.
- Automatic Type Conversion karta hai:
  Agar string "100" aayi aur int chahiye, to ye automatically 100 bana dega.
- Clear Errors: Agar data galat ho, to exact field aur reason batata hai.
- FastAPI aur Settings/Config management me standard tool hai.


3. Important Concept: Static vs Runtime
---------------------------------------
- Python Type Hints (mypy / Pylance):
  Ye sirf code likhte waqt VS Code me warning dikhate hain. Program chalne par ye kuch nahi rokte.
- Pydantic:
  Ye program chalte waqt (RUNTIME par) actual data ko check karta hai aur galat hone par rok deta hai.


4. Simple Code Example:
-----------------------
from pydantic import BaseModel, ValidationError

# Step 1: Model define karo (Rules set karo)
class User(BaseModel):
    name: str
    age: int
    is_active: bool = True  # Default value

# Case 1: Automatic Type Conversion (Parsing)
# Yaha "22" string hai, par Pydantic isse int bana dega:
u1 = User(name="Kushagra", age="22")
print(u1.age)        # 22
print(type(u1.age))  # <class 'int'>

# Case 2: Galat Data aane par Error (Validation)
try:
    u2 = User(name="Rahul", age="twenty")
except ValidationError as e:
    print("Data Galat Hai:")
    print(e)


5. One-Line Summary:
--------------------
"Pydantic = Type Hints ke zariye Runtime Data Validation + Type Conversion"


pydantic --> Data validate and setting management
